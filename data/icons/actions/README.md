# Bundled Symbolic Action & Zoom Icons

The symbolic action and navigation icons in this directory are bundled directly into Jots' GResource (`/io/github/comicdeed/jots/icons`) to guarantee 100% consistent, monochrome rendering across all desktop environments (GNOME, KDE Plasma, XFCE, Windows, macOS) and portable package formats (Flatpak, AppImage).

### Icon Inventory
- `list-add-symbolic.svg`: Create new sticky note (`+`)
- `user-trash-symbolic.svg`: Delete sticky note
- `view-list-symbolic.svg`: Full-text search and note index
- `face-smile-symbolic.svg`: Toggle Scribbly handwriting aesthetic
- `open-menu-symbolic.svg`: Overflow settings & note options popover
- `zoom-in-symbolic.svg`: Magnifying glass zoom in ($\oplus$)
- `zoom-out-symbolic.svg`: Magnifying glass zoom out ($\ominus$)
